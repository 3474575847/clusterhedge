Explore material risk and supply chains.

ClusterHedge is an experimental Flask app for exploring material cost exposure, proxy-ETF relationships, simulations, and geopolitical supply-chain scenarios.

What the project includes

Materials and projects

Record project materials, quantities, estimated costs, and optional locations in a local Flask application.

Risk exploration

Explore Monte Carlo cost simulations, proxy-ETF comparisons, hedge estimates, and historical backtests.

Supply-chain scenarios

Inspect modeled geopolitical scenarios, affected trade routes, and illustrative commodity price shocks.

Research prototype

Review the Python source, knowledge-base data, and tests; adapt the project for experimentation and learning.

Download and run on your computer

Python 3.11 or newer is recommended. The full setup guide is available as a downloadable Markdown file. You can also use these quick-start commands on macOS or Linux:

  1. Download the source ZIP and extract it, or clone the repository.
  2. From the project folder, create and activate a virtual environment and install requirements:
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python app.py

Then open http://127.0.0.1:5011. On Windows, use .venv\Scripts\activate and copy .env.example to .env using File Explorer or PowerShell.

Important limitations

This page documents the project; it does not host the Flask application. The app is an experimental prototype, not production financial software or financial advice.

Local runs use SQLite. The app has no user accounts or access controls, so do not expose a deployment containing non-public data. Some features request data from Yahoo Finance via yfinance and the OpenStreetMap Overpass API. Those features currently do not require users to configure API keys, but rely on third-party availability and terms.

Some dependencies, especially geospatial libraries, may require platform-specific setup. See the README and setup guide for details.
