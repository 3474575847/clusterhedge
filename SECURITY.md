# Security policy

## Supported versions

This is an early-stage project. No version is currently covered by a security
support commitment.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities, credentials, or personal
data in a public issue.

**Security contact:** [jindalaryan99@gmail.com](mailto:jindalaryan99@gmail.com).
Email is not guaranteed to be encrypted; do not include credentials or
unnecessary sensitive data. Public GitHub issues are not a private reporting
channel.

## Deployment warning

The current app has no authentication or per-user access controls. Do not put
confidential project data in an internet-accessible instance.
