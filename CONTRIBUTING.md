# Contributing

Thanks for your interest in ClusterHedge. Contributions are welcome, but the
project is an experimental prototype and does not yet have a formal release or
support process.

## Before opening a pull request

1. Open an issue to discuss substantial changes.
2. Keep changes focused and avoid including credentials, `.env` files, local
   databases, generated caches, or personal data.
3. Run the tests:

   ```bash
   python -m unittest discover -s tests
   ```

4. Describe behavior changes, limitations, and any new external data sources
   in the pull request.

By submitting a contribution, you agree that it may be distributed under the
repository's MIT License.
